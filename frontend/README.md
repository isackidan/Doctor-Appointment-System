# 🩺 Lumina Health - Frontend Portal

This directory contains the React 19 + Vite + Tailwind CSS v4 frontend for the **Lumina Health Hospital ERP System**.

For the full project documentation, architecture, backend setup, database migration, and credentials guide, please refer to the root [README.md](../README.md).

## 🚀 Quick Run (Frontend)

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev
```

The application will start at: `http://localhost:5173`
